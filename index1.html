Vertex Coloring • Sub-Page 1: Motivation & Context

Why Do We Color Vertices? Modeling Clashes & Resource Reuse

In many allocation and scheduling problems, distinct items compete for reusable slots, channels, or hardware units, while certain pairs cannot share the same assignment. Below are two concrete applications structured around the core question, the underlying conflict problem, the graph-based solution, and why that naturally motivates vertex coloring.

Application 01 • Exam Scheduling Course = Vertex • Clash = Edge

Mathematical Framing: Let $C = \{A, B, C, D, E\}$ be the set of courses, and let $G = (V, E)$ be the conflict graph with $V = C$ and $E = \{uv : \text{at least one student is enrolled in both } u \text{ and } v\}$, where $E = \{AB, AC, BC, BD, CD, DE\}$.

Conflicts & Cliques: Because $\{A, B, C\}$ forms a triangle ($K_3$), courses $A$, $B$, and $C$ pairwise conflict and require distinct slots; similarly, conflicts on $D$ and $E$ constrain feasible pairings.

What the Minimum Will Be: A valid slot assignment is a proper coloring $f: V \to \{1, 2, \dots, k\}$ with $f(u) \ne f(v)$ for all $uv \in E$, so the minimum number of exam slots is the chromatic number $\chi(G) = 3$ (with $\omega(G) = 3$ giving the lower bound and one optimal partition being $\{A, D\}$, $\{B, E\}$, and $\{C\}$).

Application 02 • Register Allocation Variable = Vertex • Overlap = Edge

Question: Fewest CPU registers so overlapping live variables don't overwrite each other?

Problem: Registers are scarce; sharing one across overlapping live ranges corrupts data.

Solution: Model variables as vertices and overlapping live ranges as edges.

Why Vertex Coloring: Registers are colors and edges forbid equal colors → min registers = $\chi(G)$.

Vertex Coloring • Sub-Page 2: Definitions & Theorems

Core Definitions, Bounds, Graph Operations & Brooks' Theorem

Definition • Vertex Coloring

Given a graph $G=(V,E)$ and a color set $\mathcal{C}$, a vertex coloring is a function $c: V(G) \to \mathcal{C}$ assigning a color $c(v)$ to each vertex $v \in V(G)$.

Definition • Proper Coloring & $k$-Colorability

A coloring is proper if $c(u) \ne c(v)$ for every edge $uv \in E(G)$. A proper coloring using at most $k$ colors is a proper $k$-coloring, and $G$ is $k$-colorable if one exists.

Definition • Color Classes & Chromatic Number

Each set $V_i = \{v \in V(G) : c(v) = i\}$ is a color class (an independent set). The chromatic number $\chi(G) = \min\{k : G \text{ is } k\text{-colorable}\}$.

Definition • Clique, Independence, Diameter & Operations

Clique number $\omega(G)$ is the max clique size; independence number $\alpha(G)$ is the max independent set size; $\operatorname{diam}(G) = \max d(u,v)$. Disjoint union is $G_1 + G_2$ and join is $G_1 \vee G_2$.

Key Theorems & Bounds

Theorem • Basic Bounds on Chromatic Number

For a graph $G$ of order $n \ge 1$, $1 \le \chi(G) \le n$. Moreover, $\chi(G) = 1 \iff E(G) = \emptyset$, and $\chi(G) = n \iff G \cong K_n$.

Theorem & Corollary • Bipartite Graphs & Odd Cycles

A nonempty graph $G$ is $2$-colorable ($\chi(G) = 2$ if $E(G) \ne \emptyset$) if and only if $G$ is bipartite, which holds if and only if $G$ contains no odd cycle.

Theorem • Degree Bound & Diameter Bound

For every finite simple graph, $\chi(G) \le \Delta(G) + 1$. For a connected graph of order $n$ and diameter $d$, $\chi(G) \le n - d + 1$.

Theorem • Disjoint Union & Join Operations

For pairwise disjoint graphs $G_1, \dots, G_k$, $\chi(G_1 + \dots + G_k) = \max_i \chi(G_i)$. For their join, $\chi(G_1 \vee G_2) = \chi(G_1) + \chi(G_2)$.

Theorem • Clique & Independence Number Bounds

For every graph $G$ of order $n$, $\chi(G) \ge \omega(G)$ and $\frac{n}{\alpha(G)} \le \chi(G) \le n - \alpha(G) + 1$.

Theorem • Brooks' Theorem

Let $G$ be a connected graph with maximum degree $\Delta(G)$. If $G$ is neither a complete graph nor an odd cycle, then $\chi(G) \le \Delta(G)$.

Edge Coloring • Sub-Page 1: Motivation & Context

Why Do We Color Edges? Scheduling Matches & Shared Endpoints

When the items to schedule or assign channels are edges and conflicts happen at shared endpoints, vertex coloring is not enough. Here are two concise applications with diagrams showing why edge coloring is needed.

Application 01 • Round-Robin Tournament Team = Vertex • Match = Edge

Question: Fewest tournament rounds so no team plays twice in the same round?

Problem: Two matches sharing a team cannot run simultaneously; one match per round is slow.

Solution: Represent teams as vertices, matches as edges, and each round as a matching.

Why Edge Coloring: Clashes occur on incident edges sharing a vertex → minimum rounds = $\chi'(G)$.

Application 02 • Shared Hub Links & Line Graph $\chi'(G) = \chi(L(G))$

Question: Distinct channels needed for links sharing a common hub without interference?

Problem: Links meeting at a node clash if given the same channel simultaneously.

Solution: Color edges directly or convert each edge $e$ into a vertex $x_e$ in line graph $L(G)$.

Why Edge Coloring: Models link-incidence directly and unifies with vertex coloring via $\chi'(G) = \chi(L(G))$.

Edge Coloring • Sub-Page 2: Definitions & Theorems

Edge Coloring, Line Graphs, Matchings, König & Vizing

Definition • Proper Edge Coloring & Chromatic Index

Two distinct edges are adjacent if they share an endpoint. A proper edge coloring assigns distinct colors to adjacent edges; the minimum colors needed is the chromatic index $\chi'(G)$ ($\chi'(G)=0$ if $E(G)=\emptyset$).

Definition • Line Graph $L(G)$

The line graph $L(G)$ has vertex set $V(L(G)) = \{x_e : e \in E(G)\}$, with $x_e x_f \in E(L(G))$ if and only if edges $e$ and $f$ share a common endpoint in $G$.

Definition • Matching & Matching Number

A matching is a set of pairwise non-adjacent edges (no common endpoints). Its maximum size is the matching number $\alpha'(G)$.

Definition • Class 1, Class 2 & Overfull Graphs

A simple graph is Class 1 if $\chi'(G)=\Delta(G)$ and Class 2 if $\chi'(G)=\Delta(G)+1$. A simple graph of order $n$ is overfull if $|E(G)| > \lfloor n/2 \rfloor \Delta(G)$.

Key Theorems & Results

Theorem • Line Graph Equivalence

For every simple graph $G$, $\chi'(G) = \chi(L(G))$.

Theorem • Edge Color Classes as Matchings

In every proper edge coloring, each nonempty color class is a matching; conversely, partitioning $E(G)$ into disjoint matchings yields a proper edge coloring.

Theorem • Degree & Matching-Number Lower Bounds

For any graph with at least one edge, $\chi'(G) \ge \Delta(G)$ and $\chi'(G) \ge \left\lceil \frac{|E(G)|}{\alpha'(G)} \right\rceil$.

Theorem • König's Line Coloring Theorem

If $G$ is a bipartite graph, then $\chi'(G) = \Delta(G)$.

Theorem • Vizing's Theorem, Overfull Graphs & Hamiltonian Cubic Graphs

For every simple graph $G$, $\Delta(G) \le \chi'(G) \le \Delta(G) + 1$. Every overfull simple graph is of Class 2 (and no even-order simple graph is overfull). Every Hamiltonian cubic graph is of Class 1 ($\chi'(G) = 3$).

Default Greedy Rule — Pseudocode Given Edge Order 
1. Take edges in given order e₁, e₂, ..., eₘ.2. Mark all edges as uncolored.3. For each edge e = uv in sequence:4.   Collect colors used on edges incident to u or v.5.   Assign smallest color c not used on any incident edge.6. Output edge coloring (each color class is a matching).
Welsh–Powell Algorithm (Edge / L(G)) — Pseudocode Decreasing Incident Degree 
1. For each edge e = uv, compute incident weight w(e) = deg(u) + deg(v) - 2.2. Sort edges in non-increasing order of w(e) (Welsh–Powell order).3. For each edge e in the sorted order:4.   Find colors already used on adjacent edges sharing an endpoint.5.   Assign smallest available color k ≥ 1.6. Output coloring and compare with Vizing bounds [Δ, Δ+1].
